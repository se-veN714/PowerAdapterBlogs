# PAdif MCP 工具安全与长文读写验收矩阵

> 对应：[TOOL_SAFETY_SPEC.md](TOOL_SAFETY_SPEC.md) v1.0，2026-11-11。
> 状态：下表仍是完整目标矩阵；实际证据及未覆盖项见[第一阶段](TOOL_SAFETY_PHASE1_VALIDATION.md)、[第二阶段](TOOL_SAFETY_PHASE2_VALIDATION.md)及[第三阶段验证](TOOL_SAFETY_PHASE3_VALIDATION.md)，不将部分覆盖标为整项通过。
> 每项实施后须补：测试名称/客户端步骤、实际结果、证据位置、运行日期；不以旧测试数量代替逐项证据。

## 1. 测试身份与通用断言

使用隔离本地测试库和临时账号：创建者 O、访客 V、协作者 C、无权用户 U、无逐篇授权的管理员 A；两篇不同文章 D1/D2、两个不同客户端连接 K1/K2、可控时钟。默认账号/资格有效，仅在对应测试中移除一个条件。

所有拒绝用例同时断言：版本、分支头、批注、回复、授权及成功回执没有意外变化；错误/日志不泄露正文或凭证。所有查询用例检查文章标题、数量和元数据是否泄漏。客户端试验仅使用专门生成的虚假凭证标记，不读取真实 WorkBuddy 凭证。

类型：S=服务/API，T=事务/并发，B=浏览器，C=真实客户端，M=迁移/维护。逐项完成情况以分期验证记录为准。

## 2. 跨工具统一边界

| ID | 前置与动作 | 必须满足的结果 | 类型 |
|---|---|---|---|
| G01 | 对全部读写工具分别移除账号、资格、人类角色、逐篇操作、scope、连接有效性之一 | 正确拒绝；tools/list 不替代 call 校验 | S |
| G02 | U/A 猜测 D1 的 article/version/annotation/branch/upload ID | 不得读标题、正文、数量、哈希或状态；隐藏对象统一 NOT_FOUND | S |
| G03 | 混用 D1/D2 的版本、批注、分支、任务 | 同属校验失败，不能拼接授权 | S |
| G04 | 伪造 main 名称、主线 branch ID 或经 patch/上传写 main | MAIN_REQUIRES_WEB_CONFIRMATION 或等价拒绝；主线头不变 | S |
| G05 | 未授权账号通过管理员/审核身份调用业务工具 | 无文章绕过；审批资格不等于正文访问 | S |
| G06 | 布尔 ID、未知字段、非法枚举、负页码、超大 ID/文本 | 稳定结构错误，不返回原文/堆栈 | S |
| G07 | 成功写后撤销文章权限，再用原 request_id 重试 | 不因命中回执泄露已失去权限的数据 | S |
| G08 | 同 request_id 同参数并发；相同 ID 改参数 | 一个业务对象与成功回执；改参数冲突 | T |
| G09 | 写入提交和撤销竞争，分别控制两种获锁顺序 | 满足线性化规则，无死锁、无撤销后偷写 | T |
| G10 | 等待锁期间移除 role/AI+ 操作、归档分支、撤销连接 | 锁后复核失败；无部分成功 | T |
| G11 | 业务写/回执/审计任一步异常 | 整体回滚；重试不产生孤儿对象 | T |
| G12 | 429、超时、500、断线、scope 不足 | 正常退避/续期/用户授权恢复；不指导提取凭证 | S/C |
| G13 | 用错误参数/文件名/正文构造带密钥内容的异常 | 响应与日志不含凭证、正文、邮箱、绝对路径、堆栈 | S |
| G14 | 阅读 token 调写工具、annotate 调版本工具、版本 scope 调批注 | 按具体操作拒绝，不借 read/global write 混合扩权 | S |
| G15 | 旧合法小请求、旧错误、可选新字段 | 旧成功合同保留；收紧项有显式错误和升级说明 | S/C |
| G16 | 大量重复句子/畸形 Markdown/极长单行触发高成本 diff 或解析 | 执行预算与复杂度限制可验证，不无限占用 Web，错误不伪报完整结果 | S |

## 3. 现有 10 个工具

| ID | 工具与场景 | 必须满足的结果 | 类型 |
|---|---|---|---|
| E01 | `list_documents` 搜索隐藏文章与翻页 | items/total 只包含实际可 AI+ 阅读文章，分页有界 | S |
| E02 | `get_workspace` 摘要、旧全文请求和超长全文 | 摘要不带正文；旧小文档兼容，超预算不静默截断，恢复入口可用 | S/C |
| E03 | `get_version` 空行、尾部换行、长行与非法范围 | 源码行号准确，视觉折行不增加行；超长行转分块入口 | S |
| E04 | `compare_versions` 跨文章、大型 diff、多页、单项超长变化 | 拒绝跨文章，版本对固定，超长单项有 before/after 正文引用可续取，不把局部 diff 标成完整 | S |
| E05 | `list_annotations` 很长正文/回复树、多页 | 注释及线程都有输出边界；所有回复可有序续取，作者时间保真 | S |
| E06 | `create_branch` 重试、撞名、路径式名称、跨文档起点 | 不覆盖原分支，不修改 main；同请求只创建一次 | S/T |
| E07 | `commit_version` 2 MiB 边界、Unicode、旧 base、失败重试 | 检查实际字节数；冲突和超限不写版本；成功只一个版本 | S/T |
| E08 | `add_annotation` 错行号、错 selected_text、跨版本 | 锚点精确且不可变；错锚点无批注，重试不重复 | S |
| E09 | `reply_annotation` 重复请求、恶意正文、伪造作者/时间 | 只追加一次真实作者/时间，文本不执行 | S/B |
| E10 | `resolve_annotation` 空说明、非法状态、并发/重复处理 | 复用已有状态转换与必填说明，不改旧作者和回复 | S/T |

## 4. 长文读取与局部修改

| ID | 工具与场景 | 必须满足的结果 | 类型 |
|---|---|---|---|
| L01 | `get_document_outline` 层级、超长标题、超多章节 | 返回固定版本及哈希；标题有界、分页明确、无全文 | S |
| L02 | `read_content_chunk` 超长单行、中文/emoji 位于块边界 | UTF-8 完整，半行标记正确，拼接恢复原规范正文 | S |
| L03 | 读取一半后分支头被别人推进 | cursor 仍绑定原不可变版本，不拼出新旧混合稿 | S/T |
| L04 | `read_content_chunk` 读取长批注/回复/处理说明；改 source_kind、复用其他文章 cursor 或丢失权限 | 所有正文可完整续取；归属链/来源哈希变化时拒绝，不拼接两个版本的处理说明；无路径读取或泄漏 | S |
| L05 | `apply_version_patch` 插入、替换、删除、空行、EOF、尾部换行 | 半开行范围语义一致，未修改部分完整保留 | S |
| L06 | patch 原文/哈希不匹配、越界、重叠、同点重复插入 | 整次失败，不模糊套用，不产生部分版本 | S/T |
| L07 | patch 第 N 项失败或结果超过 2 MiB | 一项失败全回滚，分支头和回执不变 | T |
| L08 | patch 并发头更新、权限撤销、丢回执后重试 | 不覆盖别人新头；遵守权限与幂等 | T |
| L09 | 完整响应含 text/structuredContent 双份序列化 | 实际 wire bytes 在预算内，而非仅检查原文字数 | S |

## 5. 暂存上传状态、文件与权限

| ID | 工具与场景 | 必须满足的结果 | 类型 |
|---|---|---|---|
| U01 | `begin_markdown_upload` 有效任务及同请求重试 | 绑定身份/连接/文章/分支/base，只预留一个任务配额 | S/T |
| U02 | `append_markdown_chunk` 同序号同内容、改内容、乱序、缺块 | 同内容幂等；改内容冲突；乱序可收但缺块不完成 | S/T |
| U03 | 块超限、声明尺寸小于实际、base64 膨胀、超额序号 | 在预算内中止，无磁盘超额/残留成功对象 | S |
| U04 | `get_markdown_upload_status` 任务猜测、跨用户/K1/K2 | 即使同账号不同连接也不能自动接管；无元数据泄漏 | S |
| U05 | 同 connection 正常 token 轮换后继续 | 可在实时权限与到期限制内续传，不创建新任务 | S/C |
| U06 | 新授权/新 connection 尝试复用旧任务 | 拒绝，提供新建任务或网站正常处理指引，不按名称继承 | S/C |
| U07 | `validate_markdown_upload` 原文件长度、整体/分块哈希不符 | 不进入 validated，任务失效，修正文件新建任务 | S |
| U08 | UTF-8/BOM/CRLF/CR、中文、空行、末尾换行 | 原字节哈希与规范正文哈希区分，规范化说明准确 | S |
| U09 | 二进制程序改名 .md、伪 MIME、NUL/非法 UTF-8、压缩包、空文件；对照合法文本代码示例 | 非法格式拒绝，合法稿件保真；均不执行、不解压，不仅按后缀/MIME 放行 | S |
| U10 | 路径穿越、冒号、控制字符、绝对路径、超长文件名 | 展示名校验，实际存储随机私有路径，无覆盖/目录穿越 | S |
| U11 | 校验成功后追加/替换块 | 正文被冻结，禁止更改已校验内容 | S |
| U12 | `commit_markdown_upload` 重试/并发/不同请求 ID 再提交 | 一个 upload 最多一个版本，回执一致，无分块碎片版本 | T |
| U13 | 已校验任务的 base 后来过期或分支归档 | 最终提交拒绝，不自动改 base 或写 main | T |
| U14 | 接收、校验、提交各阶段分别撤销连接/资格/角色/具体操作 | 各阶段重新检查并中止，重新开通不恢复任务 | S/T |
| U15 | `cancel_markdown_upload` 重复取消、取消已提交任务 | 取消幂等；不删除 committed version | S/T |
| U16 | 30 分钟到期与提交竞争、后台清理 | 先到期则拒绝提交；数据清理不依赖客户端；无半提交 | T/M |
| U17 | 多连接并发创建任务、慢速上传、反复重试 | 用户/连接/全局配额与速率有效，不能重复预留或绕过 | T |
| U18 | 上传中进程重启、清理中异常、磁盘满 | 状态可核对，任务不伪成功，无孤儿永久占额，无原稿损失 | T/M |
| U19 | 未授权下载/静态 URL、存储路径猜测 | 暂存不可公开获取，不作为 HTML 执行 | S/B |
| U20 | Agent 还不知道文件元数据时创建任务；网站稍后选文件，尝试重绑 manifest | awaiting_file 可创建且预留有界；合法 manifest 原子绑定后才接收正文，重复改绑拒绝 | B/S/T |

## 6. 网站、客户端与注入防护

| ID | 前置与动作 | 必须满足的结果 | 类型 |
|---|---|---|---|
| C01 | MCP 创建任务，用户在网站选择文件，再由 Agent 校验/提交 | 文件字节不经过模型参数；实际收到及提交哈希可对照 | B/C |
| C02 | 网站文件页匿名、其他用户、CSRF 缺失、原连接失效 | 拒绝；URL 没有 token，opaque ID 不等于授权 | B/S |
| C03 | WorkBuddy 不具备受控文件上传能力 | 明确不支持自动路径，网站上传仍可完成；不读凭证 | C |
| C04 | 支持的文件适配器访问清单外、凭证目录、符号链接目标、重命名密钥 | 客户端拒绝；测试用虚假 secret 标记，验证无越界文件读取 | C |
| C05 | 正文、标题、批注、回复、diff 含读取 token/执行 Shell 指令 | 当数据展示，真实客户端不调用越界工具；服务器拒绝不合规业务调用 | C/S |
| C06 | Markdown/注释含 script、事件属性、SVG 活性内容、javascript 链接 | 预览/全屏/diff/批注不执行；代码块文本保真 | B |
| C07 | 文中内网 URL、外站图片、远程附件 | 服务器不自动抓取；外站资源默认不自动加载，用户主动查看路径明确 | B/S |
| C08 | 上传页面及摘要/错误包含恶意文件名与提示注入 | 正确转义和边界标记，不把文本并入系统指令 | B/C |
| C09 | 在最多 3 个活动任务内滚动处理 7 篇各 9k–17k 汉字稿件，有中文引号、反斜线、代码块、尾部空行 | 各稿分别完整写入指定分支，有限调用参数，逐篇哈希/版本回执一致，main 不变 | C/S |
| C10 | 多文档任务中单篇失败/用户取消 | 逐篇报告实际状态，不宣称整批完成，不自动放宽权限或切换传输 | C |

## 7. 兼容、数据与发布前关卡

| ID | 前置与动作 | 必须满足的结果 | 类型 |
|---|---|---|---|
| R01 | 新增暂存模型/字段迁移，旧完整数据快照对照 | 文章、版本、批注、成员、AI+、资格及已有连接不被改写或扩大 | M |
| R02 | 旧 10 工具、旧 SDK/DCR/PKCE、刷新/撤销回归 | 小请求合同兼容；未新增凭证导出、token 透传或自动同意 | S/C |
| R03 | 成功写、失败、取消、过期、重试、清理的审计 | 关联 ID/哈希可追踪，副作用有记录，无正文/凭证/路径泄漏 | S/M |
| R04 | 服务端、网页和真实客户端证据汇总 | 三类证据分列；不以 schema/单测/HTTP200 代替客户端文件和凭证边界证明 | M |
| R05 | 全面完成本地实现前检查生产 diff | 无生产写操作；发布须用户另行授权，再走完整清单/备份/迁移/路由/数据对照 | M |

通过条件：上表适用项均有实际证据；明确声明不支持的客户端自动化分支可标“未支持”，但不能标为已通过。任一主线、权限绕过、凭证泄漏或稿件损坏用例失败均阻止本轮交付。失败项不以改提示词、抬上限或关闭校验来消除。
