# PAdif 云端私有草稿

2026-11-13。用户确认采用云端私有草稿。本轮仅本地实现与验证，不提交或部署。

## 完成标准

编辑器提供保存草稿与自动保存；关闭标签页、浏览器或重新登录后能显式恢复。保存正文不要求填写提交说明、不生成 Version、不移动分支头、不发布主线。显示云端保存时间及尚未提交状态。

## 数据与权限

- 新增 EditorDraft，按本人、文章分支和基础版本隔离；长期保存至本人删除或对应已保存草稿成功提交。不设置一天自动失效。
- 草稿只通过已登录网站会话读取和保存；创建者/协作者遵循原有文章权限，协作者不能编辑 main，归档分支不能保存。其他成员、OAuth 客户端及 MCP 不获得草稿读取权限。普通文档、版本、批注查询不包含草稿。
- 字段为正文、可选修改说明、版本级别、基础版本、并发修订标识和更新时间。请求 JSON 上限 2 MiB，不接受文件。通过 CSRF、文档可见性及写权限检查；响应禁止缓存。
- 新迁移只增加表、外键及唯一约束，不重写原版本、授权或批注数据。

## 编辑行为

- 编辑器工具栏统一为“保存草稿 / 全屏编辑 / 全屏预览”三个按钮；历史只读状态不提供写作按钮。全屏编辑复用同一个编辑器，放大为 16px，保留草稿自动保存；退出按钮或 Esc 返回。全屏内预览叠加于编辑层，先关闭预览再退出编辑。版本提交仍在普通编辑区域，保持独立操作。

- 停止输入 1.5 秒自动保存，也可手动保存。尚有未恢复的已有草稿时暂停自动保存，避免进入页面即覆盖；恢复前明确选择恢复或删除。
- 使用随机 UUID 修订标识作乐观锁；其他标签页保存或删除后重新创建的草稿，旧标签页请求返回 409，保留本地正在编辑的文字，不静默覆盖。
- 草稿以纯文本数据恢复至现有 Markdown 编辑器，正文与预览仍走原有渲染链。删除云端草稿保留当前编辑器内容，继续编辑时可重新保存。
- 分支头前进后，旧基础草稿通过链接进入对应历史节点，只读预览与复制，不自动套入新头。历史正文及主线采用规则不变。
- 云端保存成功后可以关闭页面而不要求提交版本；尚未存云端、网络失败或容量错误仍提示并保留编辑器内容。原标签页 sessionStorage 备份继续作为离线离开保护，明确不等同于云端持久草稿。
- 成功提交版本只删除本次用户/分支/base 下与提交正文及修订标识匹配的草稿。提交失败保留草稿；其他标签页的更新不会被旧提交清除。

## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 修改一半且说明为空 | 可保存草稿；版本数、分支头不变 |
| 新会话重新登录 | 显示原草稿及时间，显式恢复正文、说明、级别 |
| 另一协作者/匿名/已撤权 | 看不到本人的私有草稿；禁止无权保存 |
| 协作者 main / 归档分支 | 保存拒绝 |
| 跨文档、错误基础版本、过大或非法 JSON | 拒绝，不改变草稿或版本 |
| 两标签页并发、删除后重建 | 旧修订返回 409，本地输入保留 |
| 新版本出现后的旧基础草稿 | 单独列出，仅对应旧基础，不覆盖新正文 |
| 成功或失败提交 | 只清理成功提交的精确草稿，失败或较新草稿保留 |
| 网络失败 | 不显示成功，编辑器内容保留且可重试 |
| 1915×930、1198×715、390×844 | 控件可用，无横向溢出 |

不包含实时共同编辑、MCP 草稿工具、全文导出或生产发布。这些不是本轮完成条件。
