# PAdif 编辑器版本导航

2026-11-11，本地实现阶段，不部署。保留账号/逐篇协作权限、AI+ 与主线网页确认，历史版本不可改写。

## 状态与行为

- 版本栏显示所选分支、所载入版本（语义版本及 ID）、分支最新/历史正文只读、未修改/未保存修改；定位节点打开右抽屉并高亮节点。
- URL 使用 branch 与 version。省略 version 加载实际分支头；显式 version 必须属于本文以及所选分支或其直接分叉源，否则 404。只提供 version 时使用它的原分支。
- 世界线节点、历史列表和版本下拉均实际加载节点正文；正文、全屏预览、目录、批注、比较默认版本和选中标记同源。历史节点保留最新头的实心标记，当前浏览节点额外描边。较早选中节点仍加入精简图。
- 仅当前分支有效头且满足原有编辑权限/未归档时可编辑。历史正文只读，可回到分支最新，或从该节点新建分支。批注继续按原有权限和版本归属处理。main 采用流程不改变。
- 切换分支/节点/普通页面或提交其他表单时，有编辑修改则显示保留草稿并切换、放弃修改并切换、取消。仅正文、修改说明和版本级别可保存到当前标签页 sessionStorage；账号/文章/分支/base 隔离，最长一天。显式恢复/删除，读取草稿不自动覆盖编辑器。文件字节不保存。
- 草稿写入失败（存储不可用/超额）必须保持本页，不静默丢稿；重新加载/关闭有未保存内容时使用浏览器原生离开提示。提交编辑表单正常携带所载入 base，成功后加载新头；冲突时保留输入，不自动重设 base。
- 分支头已前进时，原 base 的保留草稿仍可在历史节点只读查看、预览与复制，不套用到新头。冲突 POST 单独标记“旧基础草稿 · 分支已更新”，保留原 base 与提交内容供处理。
- 切换后保持编辑面板展开状态、右抽屉开闭；正文切换保持编辑区位置，键盘焦点回到版本栏。抽屉局部展开/收起不触发草稿警告。

## 验收

后端：节点加载与正文/批注一致、分叉源、跨文章/错分支/非法 ID 拒绝、历史/归档/访客不可编辑、旧 base 提交冲突且无新增版本、既有发布及权限回归。

浏览器：分支/版本/节点真实切换；草稿保留/放弃/取消/恢复；说明与版本级别恢复；定位打开抽屉；离开提示；两个桌面视口及移动无溢出；main 与历史不变化。仅使用一次性本地账号与稿件。
