01 / PURPOSE

为什么存在

这里用于记录自动化、密码与安全实践、算法、个人工具，以及精神节律相关的长期探索。它首先服务于作者自己的表达和知识整理，而不是面向流量的内容社区。

02 / TRANSMISSIONS

内容方向

文章会围绕编码、音乐、滑板及其他阶段性主题展开。投稿功能只服务于受邀请的小规模协作，不开放公共注册、关注、点赞、私信或积分体系。

03 / BOARD SYSTEM

每个板块都是独立表达

Board 不只是数据库分类。新增板块意味着新的内容边界、权限范围与前端表达，因此仅由站点所有者随代码发布。协作者通过 BoardMembership 获得特定板块中的投稿、编辑或审核能力。

04 / IMPLEMENTATION

技术方式

站点基于 Django Template 与 htmx，采用服务端渲染的 HDA 架构。Devenir 主题使用暗色 CRT 扫描线、绿色信号与 Editorial 排版；后台权限由 Django Group、Permission 和 Board Policy 分层协作。
